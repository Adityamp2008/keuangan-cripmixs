Petunjuk Pengaturan Google Apps Script untuk Aplikasi Keuangan
Agar aplikasi ini dapat menyimpan dan mengambil data, Anda wajib melakukan pengaturan di Google Sheets dan Google Apps Script. Ikuti langkah-langkah di bawah ini dengan teliti.

Langkah 1: Buat Google Sheet Baru
Buka sheets.google.com.

Buat spreadsheet baru (Blank spreadsheet).

Beri nama spreadsheet, misalnya "Data Keuangan Cripmixs".

Di baris pertama, buat header kolom berikut, persis seperti ini:

Kolom A: timestamp

Kolom B: tipe

Kolom C: jumlah

Kolom D: deskripsi

Kolom E: id

Langkah 2: Buka Editor Apps Script
Dari spreadsheet yang baru Anda buat, klik menu Extensions > Apps Script.

Sebuah tab baru akan terbuka dengan editor kode. Hapus semua kode default yang ada.

Langkah 3: Salin dan Tempel Kode Script
Salin seluruh kode di bawah ini dan tempelkan ke dalam editor Apps Script yang tadi Anda buka.

// Ganti dengan nama sheet Anda jika berbeda
const SHEET_NAME = 'Sheet1'; 
const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);

function doGet(e) {
  try {
    const records = sheet.getDataRange().getValues();
    const headers = records.shift();
    
    const data = records.map(row => {
      let obj = {};
      headers.forEach((header, index) => {
        obj[header] = row[index];
      });
      return obj;
    });

    return ContentService
      .createTextOutput(JSON.stringify(data))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ error: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doPost(e) {
  try {
    const body = JSON.parse(e.postData.contents);
    
    if (body.action === 'add') {
      const { tipe, jumlah, deskripsi } = body.data;
      const timestamp = new Date().toISOString();
      const id = Utilities.getUuid();
      sheet.appendRow([timestamp, tipe, jumlah, deskripsi, id]);
      return ContentService
        .createTextOutput(JSON.stringify({ status: 'success', id: id }))
        .setMimeType(ContentService.MimeType.JSON);
    }
    
    if (body.action === 'delete') {
      const idToDelete = body.id;
      const data = sheet.getDataRange().getValues();
      // Cari baris yang cocok dengan ID (di kolom ke-5, index 4)
      for (let i = data.length - 1; i >= 1; i--) {
        if (data[i][4] == idToDelete) {
          sheet.deleteRow(i + 1); // +1 karena index sheet 1-based
          return ContentService
            .createTextOutput(JSON.stringify({ status: 'success', message: `Row with id ${idToDelete} deleted` }))
            .setMimeType(ContentService.MimeType.JSON);
        }
      }
      throw new Error("ID not found");
    }

    throw new Error("Invalid action");

  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error', message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
